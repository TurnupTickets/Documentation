# Menu

Moduł do zarządzania nawigacją strony publicznej.

## Menu główne i stopka

Istnieją dokładnie dwa menu: Menu główne i Menu stopka. Nie można tworzyć dodatkowych menu — to stały, zamknięty zestaw.

## Struktura drzewa

Każde menu to drzewo elementów — pozycje można zagnieżdżać (podmenu) i przeciągać, aby zmienić ich kolejność lub poziom zagnieżdżenia.

## Typy elementów

Każdy element menu wskazuje na jeden z typów:
- **Tag** — link do strony taga wydarzeń.
- **Strona statyczna** — link do jednej ze stron statycznych.
- **URL** — zewnętrzny lub dowolny adres wpisany ręcznie.
- **Plik** — link do przesłanego pliku.
- **Inne** — dowolna wartość tekstowa, np. dla akcji niebędącej zwykłym linkiem.
- **Kategoria** — typ zachowany wyłącznie dla zgodności ze starymi, wcześniej zapisanymi elementami; nie powinien być używany do nowych pozycji.

Każdy element ma też: tytuł (opcjonalny — jeśli pusty, używany jest tytuł z linkowanego obiektu), możliwość ustawienia jako nieklikalny (etykieta/nagłówek grupy bez linku) oraz opcję otwierania w nowej karcie.

## Usuwanie

Usunięcie elementu menu usuwa również wszystkie jego podelementy (całe poddrzewo).

## Podsumowanie

Dwa stałe menu, każde jako drzewo linków do tagów, stron statycznych, URL-i lub plików — z prostym przeciąganiem do zmiany kolejności/zagnieżdżenia i usuwaniem całych poddrzew na raz.
